# Fraud Detection Using Machine Learning

Detects fraudulent financial transactions using a Random Forest model in Python.

## Tools
Python, Pandas, Scikit-Learn

## Dataset
Financial transactions dataset (6.3M records)

## Approach
Data cleaning, feature selection, model training and evaluation

## Results
- ROC-AUC of 0.99
- Top fraud predictors: newbalanceDest, oldbalanceOrg and amount

## Recommendations
Real-time monitoring, multi-factor authentication and periodic audits
